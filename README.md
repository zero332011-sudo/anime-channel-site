# منصة قناة الأنمي — React + TypeScript

## التشغيل محليًا
1. ثبّت Node.js (الإصدار 20 أو أحدث).
2. فك ضغط `anime-platform.zip`.
3. افتح مجلد المشروع في Terminal.
4. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
5. افتح الرابط المحلي الذي يعرضه Vite.

## بناء نسخة النشر
```bash
npm run build
```
ستجد ملفات النشر داخل `dist/`.

## الموجود في النسخة الحالية
- واجهة عربية RTL متجاوبة، وضع داكن وفاتح.
- الصفحة الرئيسية، مكتبة الأنمي، صفحة التفاصيل، الكورسات، الاستشارات، والمفضلة.
- إدارة الأنمي والتصنيفات والكورسات والطلبات ومعلومات الموقع من لوحة المطور.
- رفع صور محليًا عبر المتصفح، وإضافة قائمة حلقات نصية لكل أنمي.
- تقييمات نجوم ومفضلة وبحث وفلترة وترتيب.
- حفظ البيانات في LocalStorage، مع تصدير واستيراد نسخة احتياطية JSON.

## حدود النسخة التجريبية والأمان
- التخزين محلي في المتصفح؛ لا توجد قاعدة بيانات أو مزامنة بين الأجهزة في هذه النسخة.
- كلمة مرور لوحة المطور تُنشأ عند أول دخول وتُخزن محليًا في هذا المتصفح فقط. هذا ليس نظام مصادقة آمنًا، ولا يصلح لحماية لوحة تحكم على موقع عام.
- قبل النشر العام، يجب إضافة Backend وقاعدة بيانات ومصادقة حقيقية (مثل Supabase أو Firebase أو خادم خاص)، مع تخزين الصور في Storage.
- صور البطاقات الحالية صور تجريبية ويمكن تغييرها من لوحة المطور.
- نموذج الاستشارة وحجز الكورس يحفظ الطلب محليًا فقط؛ لا يرسل بريدًا أو إشعارًا تلقائيًا.
- تقييمات الزوار محلية على نفس المتصفح وليست مجمعة من جميع الزوار.
